## Docker CLI 명령어

### 컨테이너 목록 조회
```sh
docker ps 
```

### 정지된 컨테이너 목록까지 조회
```sh
docker ps -a
```

### 컨테이너 실행(구동), 올린다, 로드한다.
```sh
docker run -d --name my-pg -e POSTGRES_PASSWORD=admin1234 -p 5432:5432 postgres:18

docker run -d --name my-pg \
-e POSTGRES_PASSWORD=admin1234 \
-p 5432:5432 postgres:18
```

### 외부 SQL 파일을 도커 컨테이너 내부로 복사
```sh
docker cp kant_shop.sql my-pg:/tmp/kant_shop.sql # docker cp 대상파일 복사할 파일
```
---------------------------------------------------
- 1번째 방법
```sh
docker exec -it my-pg psql -U postgres -f //tmp/kant_shop.sql # -f는 파일의 약자
```
- 2번째 방법
```sh
docker exec -i my-pg psql -U postgres < kant_shop.sql
```
------------------------------------------------------
### 데이터베이스를 선택(지정) 접속
```sh
docker exec -it my-pg psql -U postgres -d kant_shop  # -d = 데이터베이스 이름 지정
```

---

### 도커 불륨

```sh
docker volume ls
docker volume create [불륨명]
docker volume inspect [불륨명]
```
- 컨테이너 생성 시 불륨을 연결하기

```sh
docker run -d --name my-pg -e POSTGRES_PASSWORD=admin1234 -p 5432:5432 -v pgdata:/var/lib/postgresql postgres:18
```

```sh
docker exec -it my-pg psql -U postgres kant_shop -c "SELECT *  FROM product"
docker exec -it kant-pg psql -U postgres kant_shop -c "SELECT *  FROM product"
```
